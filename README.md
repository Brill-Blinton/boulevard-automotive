# Boulevard Automotive Center — one-page site

Built free for the shop by Ben Balitski (Beaver Falls, PA).

## Make it live (5 min, any phone or PC)
1. GitHub -> new PUBLIC repo named `boulevard-automotive` (exactly).
2. Upload `index.html` and `boulevard-automotive.vcf` from this folder (Add file -> Upload files).
3. Settings -> Pages -> Branch: `main`, folder `/ (root)` -> Save.
4. Wait ~1 min, open https://brill-blinton.github.io/boulevard-automotive/ — check it on CELLULAR.

Facts on the page come from the shop's public Google Maps listing (checked 2026-10-28).
